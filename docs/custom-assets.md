# ComfyUI_Pose-Gallery_ZH · 自定义素材目录

自定义库和内附库相互独立。选择自定义库后，只在自定义清单内寻找图片。

```text
my-pose-library/
├── data/pose-zh.json
├── img/
│   ├── my_pose_001_front.png
│   └── my_pose_001_side.png
└── thumbs/                         # 可选，缺失时回退原图
    ├── my_pose_001_front.jpg
    └── my_pose_001_side.jpg
```

`data/pose-zh.json` 使用 UTF-8，内容为非空数组：

```json
[
  {
    "id": "my_pose_001_front",
    "体系": "我的姿势",
    "姿势编号": "P001",
    "分类": "站姿",
    "姿势名称": "抬手站立",
    "角度": "正面",
    "原图": "img/my_pose_001_front.png",
    "缩略图": "thumbs/my_pose_001_front.jpg"
  },
  {
    "id": "my_pose_001_side",
    "体系": "我的姿势",
    "姿势编号": "P001",
    "分类": "站姿",
    "姿势名称": "抬手站立",
    "角度": "侧面",
    "原图": "img/my_pose_001_side.png",
    "缩略图": "thumbs/my_pose_001_side.jpg"
  }
]
```

- ID 在整个库内唯一，建议使用便于分享的稳定 ID。
- 体系和姿势编号共同决定分组；相同编号可以出现在不同体系。
- 上述字段均为非空文本，缩略图可以省略。
- 建议使用正面、斜侧、侧面、俯视、仰视，同一姿势每个角度放一张。其他角度仍可逐张浏览和输出。
- 图片路径相对于素材库根目录，使用 `/` 分隔，不能使用绝对路径或越出库目录。
- 支持 PNG、JPG/JPEG、WebP、BMP。缩略图建议与原图比例一致，原图尺寸不限。
- 无需填写「检索」，插件会根据其他字段生成搜索文本。

在「素材设置」中填入 `my-pose-library` 的绝对路径，检查保存，再切换到自定义素材目录。

增删图片后同步维护清单，并刷新图库或浏览器。执行缓存根据清单及已选图片的修改时间、大小更新。稳定 ID 可让工作流适应不同电脑路径；换电脑后重新配置目录即可。

第一版每个 ComfyUI 实例配置一个自定义目录；它是服务器级设置，连接同一实例的浏览器使用同一目录。
